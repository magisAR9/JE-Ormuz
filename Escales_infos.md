## Donées d'escales meta - données 

Source :
[IHS Maritime](https://maritime.ihs.com/)


| CHAMP | Description | Précisions éventuelles |
|---|---|---|
| **IMO/LR/IHS No.** | Numéro d'identification unique du navire attribué par l'Organisation maritime internationale (OMI). Identifiant permanent du navire, conservé tout au long de sa carrière. | |
| **MMSI** | Identifiant numérique unique à 9 chiffres attribué à une station radio maritime, permettant notamment d'identifier un navire dans le système AIS. Contrairement au numéro IMO, il peut évoluer au cours de la vie du navire. | |
| **Port** | Nom du port dans lequel le navire effectue une escale. | |
| **Prev Port** | Nom du port précédemment visité par le navire avant son arrivée dans le port considéré. | Donnée calculée automatiquement et peut comporter des erreurs |
| **MMSI** | Identifiant numérique à 9 chiffres du navire utilisé dans le système AIS (Maritime Mobile Service Identity). | |
| **Ship Name** | Nom du navire au moment de l'escale considérée. | |
| **Operator** | Nom de la compagnie ou de l'entité exploitant commercialement le navire. | |
| **Vessel Type** | Catégorie du navire selon sa typologie : porte-conteneurs, vraquier, pétrolier, navire roulier, navire à passagers, etc. | |
| **Arrival Time** | Date et heure d'arrivée du navire dans le port considéré. | |
| **Sailed Time** | Date et heure de départ du navire du port considéré. | |
| **Hours in Port** | Durée totale de l'escale dans le port, exprimée en heures. | |
| **Voyage Hours** | Durée du trajet maritime entre le port précédemment visité et le port considéré, exprimée en heures. | Donnée calculée automatiquement et peut comporter des erreurs |
| **DWT** | Port en lourd (Deadweight Tonnage) du navire, exprimé en tonnes. Il correspond à la capacité maximale de chargement du navire, incluant les marchandises, les combustibles, les approvisionnements, l'eau et les personnes. | |
